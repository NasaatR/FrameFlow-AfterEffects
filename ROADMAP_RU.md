# FrameFlow: актуальный план

Обновлено 29 октября 2026. Продукт — компактная панель команд для обычного таймлайна After Effects. Источник истины — AE. Второй редактируемый таймлайн, список всех слоёв, drag/trim/split-инспектор и thumbnails в текущий план не возвращаются.

## Готовая основа

CEP/ExtendScript, проверяемый загрузчик, сдвиг до/после курсора, Auto, четыре режима переноса, быстрые шаги, удаление паузы, копируемая диагностика, строгая проверка и ограниченное восстановление. В 2.1.1 ограниченный исходником слой можно оставлять целиком без изменений, сдвигая остальные доступные цели. Авто / Слои и ключи — стартовые значения; другой стартовый контекст запоминается только явно.

Пользователь сообщает, что предыдущая версия сейчас работает. Это не заменяет отдельную приёмку всех типов свойств, Undo/Redo и сложного медиа в реальном AE.

## Постоянные правила

- Команды используют актуальные CTI/выделение, но применение предпросмотра не расширяет показанную область и не пересчитывает другую операцию незаметно.
- Метаданные опрашиваются отдельно от сканирования ключей. План и список подробностей ограничены; нативные значения не отправляются в браузер.
- EN — язык по умолчанию; RU выбирается явно и сохраняется. Имена и нативные значения AE не переводятся.
- Предпросмотр хранит один план до 2 минут. Изменение метаданных, новая проверка или действие аннулирует предыдущий план; данные ключей повторно проверяются до записи.
- Timeout записи требует проверки, без автоматического повтора. Смена интерфейса не ослабляет блокировки, коллизии и восстановление.
- Новые версии публикуются напрямую в main по разрешению пользователя. Обновление только fast-forward с проверкой ожидаемого SHA; чужие изменения не перезаписываются. CI работает на push main. Новые ветки для обычных обновлений не нужны.
- Проверенные установочные ZIP имеют отдельные версии; выданные архивы не заменяются. Обновление начинается с закрытия панели. Если новая версия/ядро не подхватились, перезапускается AE.


## Приёмка 2.4

- Готово: четыре команды Arrange, положительный шаг Stagger и нулевой/положительный зазор Sequence; три детерминированных порядка и два якоря.
- Готово: сохранение длительности/ключей/выделения, нативный перенос слоя, индивидуальные сдвиги в плане; маркеры и длительность композиции не меняются.
- Готово в имитации: блокировки, устаревшие цели/источники/ключи, субкадры, повтор без изменений, восстановление после сбоя и отсутствие повторной записи RPC.
- Проверки конкретной сборки и браузера — VERIFICATION.json. Измерения имитации не считаются производительностью реального AE.
- Осталось в AE 25.6.4: Align In/Out, все порядки Stagger/Sequence, видео/аудио/Remap, Undo/Redo и сцена с большим числом ключей.

## Масштабирование без перегруженной панели

- **Готово в 2.4.2:** `extension/js/commands.js` — одно место для ID, EN/RU названий, размещения, контекста, аргументов и правила предпросмотра. Существующие 11 команд используют этот каталог.
- **Готово:** меню и обычные кнопки создаются из описаний и общих компонентов `extension/js/ui.js`; новые действия наследуют тему, размеры, состояния, доступность и клавиатурное поведение. Частые действия могут быть на панели; остальные — в меню. Дублирующий таймлайн не возвращается.
- **Готово:** `src/commands/*.jsxinc` — отдельные обработчики подготовки плана. Сборка подключает их без новой ветки общего диспетчера; код не подгружается из пользовательских путей во время работы. Проверяются связи UI → модуль, дубликаты, конфликты ID, иконки и итоговый ES3.
- **Готово:** рецепт для следующего агента в `docs/EXTENDING.md`, короткая навигация в `AGENTS.md`. Новая подпись/кнопка для уже поддержанного действия обычно требует только описания; новая операция — модуля и проверок. Новый API или тип изменения по-прежнему требует адаптера и правил восстановления.
- **Следующая основа по мере появления задач:** отдельный контракт анализа без записи для этапа 2.5; регистрация новых типов форм; единый источник версии для всех генерируемых метаданных.
- **Планируется:** составные команды «одна кнопка — несколько действий» с единым расчётом, одним предпросмотром и одной группой Undo. Сначала зависимости и восстановление; последовательная отправка нескольких независимых записей не считается готовым решением.
- **Позже, при реальной необходимости:** избранные команды, порядок/видимость кнопок и поиск по командам с версионируемыми настройками. Не добавлять новые постоянные панели ради каждого инструмента.

Критерий удобного расширения: агент добавляет описание и, когда нужен новый алгоритм, отдельный обработчик; существующие команды, оформление, настройки, загрузчик и правила применения сохраняются. Неподдержанные типы действий отмечаются явно, без обещания универсальной безопасной кнопки для любого API.

## Оптимизация 2.4.2

- Подготовленная 2.4.1 сохраняется без замены выданного ZIP; основа и улучшения входят в новую 2.4.2.
- Изменение шага не пересоздаёт списки области/режима и не применяет тему заново. Неизменённые настройки не создают запись; реальные изменения по-прежнему сохраняются с подтверждением.
- Закрытый или заменённый пользователем предпросмотр не открывается повторно после запоздалого ответа AE. Это отмена показа результата, а не обещание отменить выполняемый JSX.
- Пользователь подтвердил постоянное разрешение на обычные проверенные обновления main этого репозитория; публикации используют проверку ожидаемого SHA и сохраняют чужие изменения.
